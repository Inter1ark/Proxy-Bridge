# ProxyBridge для macOS

Сборка без подписи Apple и без App Store. Поддерживаются Apple Silicon (`ProxyBridge-<версия>-macOS-arm64.zip`) и Intel (`-x64.zip`). Минимальная версия системы: macOS 12.

## Установка и первый запуск

1. Распакуйте zip (двойной клик или `unzip`). Появится `ProxyBridge-arm64.app` или `ProxyBridge-x64.app`, можно переименовать в `ProxyBridge.app` и перенести в «Программы».
2. Приложение не подписано, поэтому Gatekeeper при первом запуске покажет предупреждение. Два способа открыть:
   - правый клик по приложению, «Открыть», затем ещё раз «Открыть» в диалоге;
   - или в терминале снять карантин: `xattr -dr com.apple.quarantine /путь/к/ProxyBridge-arm64.app`
3. Если система пишет, что приложение «повреждено» или не запускается, выполните из папки с распакованным приложением `sh fix-perms.sh` (снимает карантин и ставит права на исполняемые файлы), затем повторите шаг 2.

## Как это работает

При нажатии CONNECT приложение запускает помощник `pbcore` (лежит в `Contents/MacOS/`) с правами администратора: macOS покажет стандартный диалог с запросом пароля. Пароль нужен, чтобы создать виртуальный сетевой интерфейс `utun` и изменить таблицу маршрутов. Запрос пароля показывается при каждом подключении.

Помощник направляет весь TCP-трафик системы через указанный SOCKS5 или HTTP прокси. При нажатии DISCONNECT или закрытии приложения маршруты снимаются и интерфейс удаляется. Если приложение упадёт, помощник сам завершится в течение пары секунд (следит за PID приложения); системный маршрут по умолчанию при этом не трогается, поэтому сеть не пропадёт.

## Ограничения этой версии

- Только TCP. UDP не проксируется (приложения получают «порт недоступен» и обычно переходят на TCP).
- DNS идёт напрямую на `1.1.1.1` по UDP (не через прокси).
- IPv6 не перехватывается.
- Split Tunnel (прокси для отдельных программ) на macOS пока недоступен: вкладка показывает «На macOS пока недоступно».
- Автозапуск и сворачивание в трей могут вести себя иначе, чем на Windows.

## Как проверить

1. Подключитесь в приложении.
2. В терминале: `curl -s https://api.ipify.org` должен вернуть IP прокси.
3. `netstat -rn -f inet | head -20` покажет маршруты `0/1` и `128/1` через `utunN`, а также host-маршрут для IP прокси через ваш обычный шлюз.
4. Лог помощника: `~/.config/ProxyBridge/pbcore.log`.
5. Отключитесь: маршруты `0/1` и `128/1` должны исчезнуть.

Помощник можно запустить и вручную без GUI, см. `core-go/README.md`.

## Сборка

На Windows: `.\mac\build-mac.ps1` (нужны .NET 9 SDK, Go и Python 3). Скрипт собирает `pbcore`, публикует GUI для `osx-arm64` и `osx-x64`, складывает `.app` в `mac/dist/` и упаковывает zip, проставляя права 0755 на исполняемые файлы (Windows сам их хранить не умеет). На macOS то же самое делает GitHub Actions workflow `.github/workflows/mac-build.yml` при пуше тега.
