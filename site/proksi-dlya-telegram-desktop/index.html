Прокси для Telegram Desktop на ПК

Рабочий Telegram должен ходить через корпоративный прокси или у каждого аккаунта нужен свой IP? Разберём встроенные настройки Telegram Desktop, их пределы и случаи, когда ProxyBridge действительно упрощает работу.

Встроенный прокси в Telegram Desktop

Начнём с честного: у Telegram Desktop свои настройки прокси, и часто их достаточно. Открой «Настройки», затем «Продвинутые настройки», «Тип соединения» и выбери «Использовать собственный прокси». Можно добавить SOCKS5, HTTP или MTProto, указать сервер, порт, логин и пароль. Есть отдельный флажок, чтобы через прокси шли и звонки. Если у тебя один аккаунт и один прокси для телеграм на ПК, этого хватит, и ставить ничего не нужно.

Учти, что встроенный прокси касается только самого Telegram. Ссылки из чатов открываются в браузере, а он ходит в сеть по своим правилам; файлы, которые ты потом загружаешь в CRM или облако, тоже уходят с другого адреса. Для личной переписки это неважно, а в рабочих процессах, где все действия должны идти с одного корпоративного IP, такой разрыв приходится закрывать отдельно.

Как сделать в ProxyBridge

  1. Выключи встроенный прокси в Telegram Desktop, чтобы не было двойного подключения.
  2. В ProxyBridge открой Split Tunnel и через Browse выбери Telegram.exe.
  3. Укажи рабочий прокси в формате ip:port:user:pass.
  4. Добавь правила для других программ, которым нужен свой прокси.
  5. Нажми APPLY SPLIT TUNNELING и проверь, что Telegram подключился.

Несколько аккаунтов телеграм с разными прокси

В одном Telegram Desktop можно держать несколько аккаунтов, но настройки соединения у них общие: все пойдут через один прокси. Чтобы у каждого аккаунта был свой IP, запускают отдельные копии программы со своей папкой данных, например портативную версию в разных каталогах или запуск с параметром -workdir. В каждой копии задаётся свой прокси во встроенных настройках.

Здесь важно понимать ограничение ProxyBridge. Split Tunnel различает программы по имени процесса, а все копии называются telegram.exe. Значит, через ProxyBridge они получат один и тот же прокси. Для схемы «один аккаунт, один IP» основной инструмент: встроенные настройки в каждой копии.

Когда удобнее ProxyBridge

  • Корпоративный прокси. Компания просит, чтобы через её сервер ходил весь рабочий софт: Telegram, браузер, CRM. В ProxyBridge это настраивается в одном окне, и при смене адреса не нужно обходить каждую программу.
  • Разделение трафика. Telegram идёт через рабочий прокси, браузер через другой, остальное напрямую: каждой программе свой адрес в Split Tunnel.
  • Программы без своих настроек прокси рядом с Telegram, которые должны выходить в сеть с того же рабочего IP.
  • Команда на нескольких ПК. Прокси сотрудников хранятся в текстовом файле, его загружают через Proxy List и Load from File, а нужный адрес подключают кнопкой Connect.
  • Проверка перед выдачей сотруднику. HTTP-прокси проверяется через VERIFY: доступен ли он, страна, город и внешний IP.

Как не запутаться в настройках

Выбери один способ для конкретной копии Telegram. Если включены встроенный прокси и одновременно правило ProxyBridge для telegram.exe, соединение пройдёт через два сервера подряд: это медленнее и сложнее в диагностике. MTProto ProxyBridge не поддерживает, только HTTP и SOCKS5, поэтому MTProto-прокси оставляй во встроенных настройках.

Звонки Telegram используют UDP, а ProxyBridge передаёт через прокси только TCP, так что при работе через него звонки пойдут напрямую. Если звонкам тоже нужен прокси, используй встроенный режим с флажком для звонков. И не включай VPN вместе с ProxyBridge: два перехватчика трафика мешают друг другу.

Частые вопросы

Как поставить прокси для телеграм на пк?

В Telegram Desktop открой «Настройки», «Продвинутые настройки», «Тип соединения» и включи собственный прокси. Поддерживаются SOCKS5, HTTP и MTProto, с логином и паролем.

Можно ли сделать разные прокси для нескольких аккаунтов telegram desktop?

В одной копии программы нет, прокси общий для всех аккаунтов. Запусти отдельные копии со своей папкой данных и задай в каждой свой прокси во встроенных настройках.

Зачем ProxyBridge, если в Telegram есть свой прокси?

Для одного Telegram он не обязателен. Он пригодится, когда через прокси должны идти и другие программы, в том числе без своих настроек прокси, или когда удобнее управлять адресами в одном окне.
