Прокси для Firefox: встроенная настройка и SOCKS5 с паролем

Firefox умеет работать с прокси сам, и для многих задач этого хватает. Разберём, где находятся его сетевые параметры, где они упираются в ограничения и когда удобнее отдать браузер ProxyBridge.

Встроенная настройка прокси в Firefox

В отличие от Chrome и Яндекс Браузера, у Firefox собственные сетевые параметры, и настройка прокси Firefox делается прямо в браузере. Открой «Настройки», на вкладке «Основные» прокрути вниз до «Параметров сети» и нажми «Настроить». Там пять режимов: без прокси, автоопределение, системные настройки, ручная настройка и URL автоматической настройки. Прокси для Firefox, заданный вручную, работает только в этом браузере и не трогает остальные программы Windows. В ручном режиме доступны такие поля:

  • HTTP прокси и порт, с флажком «Также использовать этот прокси для HTTPS».
  • Узел SOCKS и порт, переключатель SOCKS 4 или SOCKS 5.
  • «Отправлять DNS-запросы через прокси при использовании SOCKS 5»: с этим флажком адреса сайтов определяет прокси-сервер, а не DNS твоего провайдера.
  • «Не использовать прокси для»: исключения, например локальные адреса.

Как сделать в ProxyBridge

  1. Поставь в Firefox режим «Без прокси», чтобы не было двойного подключения.
  2. В ProxyBridge на вкладке «Прокси» вставь прокси с авторизацией, например socks5://user:pass@ip:port, и нажми «Добавить».
  3. На вкладке «Главная» нажми «Добавить программу» и выбери firefox.exe из запущенных программ.
  4. Справа в строке Firefox выбери добавленный прокси и нажми «Подключить».
  5. Открой в Firefox сайт проверки IP и убедись, что адрес сменился.

Где встроенных настроек не хватает

Для HTTP-прокси Firefox спросит логин и пароль во всплывающем окне. У SOCKS5 полей авторизации в настройках нет совсем, поэтому SOCKS5 с логином и паролем штатно не подключить. Некоторые расширения умеют передавать учётные данные через программный интерфейс Firefox, но это ещё одна программа с доступом ко всем сайтам. Второе ограничение: прокси задаётся на весь профиль, все вкладки идут через один адрес. Третье: если через тот же или другой прокси должны работать программы вне браузера, Firefox тут не поможет, его настройки касаются только его самого.

Firefox через ProxyBridge: правило для firefox.exe

ProxyBridge не зависит от того, что выбрано в браузере: он перехватывает соединения процесса firefox.exe на уровне сетевого драйвера. Ты добавляешь Firefox на вкладке «Главная» кнопкой «Добавить программу», выбираешь для его строки прокси вида socks5://user:pass@ip:port и нажимаешь «Подключить». Авторизация SOCKS5 при этом работает, а другие программы получают свои строки или идут напрямую через «Все остальные программы». В самом Firefox поставь «Без прокси», иначе выйдет цепочка: браузер подключится к своему прокси, а ProxyBridge отправит это подключение ещё через один.

DNS и WebRTC: что меняется

Флажок про DNS через SOCKS 5 действует только во встроенном режиме. Под ProxyBridge обычные DNS-запросы на порт 53 всегда идут напрямую, отдельной настройки для этого нет. Если же в Firefox включён DNS через HTTPS, такие запросы идут по TCP и уходят в прокси вместе с остальным трафиком браузера.

Через прокси вообще передаётся только TCP, а WebRTC работает по UDP и может показать сайту реальный IP. В Firefox его можно выключить без расширений: в about:config установи media.peerconnection.enabled в false. После этого перестанут работать звонки и видеосвязь в браузере.

Что выбрать

  • Один HTTP-прокси или SOCKS5 без пароля только для Firefox: хватит встроенной ручной настройки.
  • SOCKS5 с логином и паролем: ProxyBridge или расширение.
  • Firefox и ещё пара программ на разных прокси: ProxyBridge, где у каждой программы своя строка на вкладке «Главная» со своим прокси.
  • Включён VPN: выключать его не нужно, ProxyBridge работает вместе с VPN-клиентами вроде WireGuard и AmneziaWG.

Частые вопросы

Почему Firefox не спрашивает пароль от SOCKS5 прокси?

В настройках Firefox нет авторизации для SOCKS5, браузер подключается без логина и пароля. Используй прокси с привязкой по IP, расширение или внешний клиент, например ProxyBridge.

Что значит «Отправлять DNS-запросы через прокси при использовании SOCKS 5»?

Адрес сайта превращает в IP сам прокси-сервер, а не DNS твоего провайдера. Флажок работает только при встроенной настройке SOCKS 5 в Firefox.

Firefox не использует системный прокси Windows, почему?

Скорее всего, в параметрах сети выбран режим «Без прокси» или ручная настройка. Чтобы браузер брал системный прокси, выбери «Использовать системные настройки прокси».
