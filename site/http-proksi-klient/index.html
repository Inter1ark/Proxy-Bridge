HTTP-прокси клиент для Windows

HTTP-прокси есть у любого провайдера, но Windows передаёт его далеко не всем программам. ProxyBridge подключает HTTP-прокси на уровне драйвера и даёт проверить его до подключения.

Что такое HTTP-прокси клиент и чем он отличается от настроек Windows

HTTP-прокси клиент нужен, когда встроенной настройки мало. Подключить HTTP прокси в Windows можно и без программ: «Параметры», «Сеть и Интернет», «Прокси», ручная настройка, адрес и порт. Но эту настройку учитывают в основном браузеры и программы, которые обращаются к системным параметрам. Почтовый клиент со своим сетевым кодом, консольная утилита или игровой лаунчер её проигнорируют. Логина и пароля в параметрах Windows нет, браузер спросит их в отдельном окне, а остальные программы обычно молча получат ошибку.

ProxyBridge ничего не просит у программ. Он перехватывает TCP-соединения через WinDivert и открывает для каждого туннель через HTTP-прокси методом CONNECT. Этот метод передаёт не только веб-страницы: через него проходят любые TCP-соединения, включая HTTPS, почтовые протоколы и API-запросы скриптов. Слово HTTP здесь описывает способ общения с прокси, а не тип сайтов: HTTPS-сайты через такой прокси открываются так же, как обычные.

Как сделать в ProxyBridge

  1. Скопируй HTTP-прокси из кабинета провайдера, вставь его на вкладке «Прокси» и нажми «Добавить».
  2. Нажми «Проверить» и сверь задержку, страну, город и внешний IP.
  3. Если через прокси должен идти весь компьютер, выбери его в строке «Все остальные программы» на вкладке «Главная».
  4. Для одной программы нажми «Добавить программу», выбери её и назначь этот прокси справа в строке.
  5. Нажми «Подключить»: дальше правки в таблице применяются сразу, без переподключения.

Проверка до подключения

Любой прокси в ProxyBridge можно проверить заранее, и HTTP не исключение. Добавь строку http://user:pass@ip:port на вкладке «Прокси» и нажми «Проверить». Проверка идёт через сам прокси, и программа покажет задержку, страну и город, флаг и внешний IP. Если прокси куплен «под Германию», а проверка показывает другую страну, лучше выяснить это до того, как через него зайдёт рабочий аккаунт. Неверный пароль или закрытый порт тоже видны сразу: появится «неверный логин или пароль» или «прокси недоступен».

Строку можно ввести и в коротком формате ip:port:user:pass, как её часто выдают в кабинете провайдера. Добавленный прокси сохраняется на вкладке «Прокси», его можно переименовать, и в следующий раз копировать строку заново не придётся. Если провайдер выдал прокси сразу на несколько стран, вставь их все, по одному в строке, и нажми «Проверить все»: будет видно, какой адрес какой стране соответствует, без подключения к каждому.

HTTP-прокси клиент на примерах

Корпоративный сценарий: компания выдаёт сотрудникам HTTP-прокси с логином и паролем, и через него должен ходить не только браузер, но и клиент учётной системы, рабочий мессенджер и консоль разработчика. Вписывать прокси в каждую программу долго, а часть из них принимает только адрес без пароля. В ProxyBridge это решается выбором прокси в строке «Все остальные программы» и одной кнопкой «Подключить». Второй сценарий: SEO-специалист снимает позиции десктопной программой и хочет, чтобы через HTTP-прокси шла только она. Тогда для неё добавляется отдельная строка кнопкой «Добавить программу», «Все остальные программы» остаются на «Напрямую», и браузер с почтой работают без прокси. Третий: разработчик проверяет, как его API отвечает на запросы из другой страны, и пускает через HTTP-прокси только тестовый скрипт.

Какие задачи решает

  • Направляет через HTTP-прокси программы, которые не читают системные настройки Windows.
  • Передаёт логин и пароль прокси за программу, без всплывающих окон.
  • Показывает страну, город и внешний IP прокси до подключения.
  • Позволяет пустить через HTTP-прокси одну программу, оставив остальные напрямую.
  • Подходит для корпоративного HTTP-прокси, через который компания требует выходить в сеть.

Ограничения

Как и с SOCKS5, через прокси идёт только TCP, UDP уходит напрямую, поэтому звонки и онлайн-игры этим способом не проксируются. Прокси должен поддерживать метод CONNECT: так работают почти все платные HTTP-прокси, но старые прокси, рассчитанные только на обычные веб-запросы, могут его не принимать. Адрес берут у провайдера или покупают прямо в программе, на вкладке «Получить прокси».

Если «Проверить» показывает «прокси недоступен» или «нет ответа», а провайдер уверяет, что всё работает, проверь три вещи: правильный ли порт (HTTP и SOCKS5 часто висят на разных портах), не истёк ли срок аренды и не включена ли у провайдера авторизация только по IP. VPN-клиент при этом выключать не нужно: ProxyBridge работает вместе с WireGuard, AmneziaWG и подобными.

Уточнение: если у провайдера есть оба протокола, HTTP удобен там, где компания разрешает только веб-прокси, а SOCKS5 тем, что он не зависит от поддержки CONNECT на стороне сервера.

Частые вопросы

Как подключить http прокси в windows 10 для всех программ?

Системная настройка Windows действует только на программы, которые её читают. Чтобы весь TCP-трафик шёл через HTTP-прокси, нужен клиент с перехватом на уровне драйвера, например ProxyBridge с прокси в строке «Все остальные программы».

Почему http прокси с логином и паролем не работает в программе?

Многие программы не умеют передавать авторизацию прокси или не показывают окно ввода. ProxyBridge берёт логин и пароль из строки http://user:pass@ip:port и подставляет их сам.

Можно ли узнать страну http прокси перед подключением?

Да, в ProxyBridge для этого есть кнопка «Проверить» на вкладке «Прокси». Она показывает задержку, страну, город, флаг и внешний IP.
