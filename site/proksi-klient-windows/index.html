Зачем отдельный прокси-клиент для Windows

Прокси-клиент для Windows нужен там, где встроенных средств не хватает. В «Параметрах» Windows 11 и 10 есть раздел «Прокси», но это скорее подсказка для программ, чем правило: браузеры на Chromium его читают, а многие клиенты, консольные утилиты и приложения со своим сетевым стеком просто идут напрямую. Поля для логина и пароля там тоже нет, и SOCKS5 с авторизацией так не задать.

ProxyBridge работает иначе. Программа ставит сетевой драйвер WinDivert и перехватывает соединения до того, как они уйдут в сеть. Поэтому самому приложению ничего настраивать не нужно: оно даже не знает, что его трафик идёт через прокси. Версия 3.2.0 работает на Windows 10 и 11 (64-bit), установщик запускается от имени администратора, потому что права нужны драйверу.

Как сделать в ProxyBridge

  1. Скачай установщик ProxyBridge и запусти его от имени администратора.
  2. При первом запуске введи ключ лицензии в окне активации.
  3. Вставь адрес прокси на вкладке Dashboard в формате http://user:pass@ip:port или socks5://user:pass@ip:port.
  4. Для HTTP-прокси нажми VERIFY и проверь страну и внешний IP.
  5. Нажми CONNECT для всей системы или настрой правила на вкладке Split Tunnel.

Два режима работы

Системный режим отправляет весь TCP-трафик компьютера через один прокси, его включает круглая кнопка CONNECT. Split Tunnel устроен тоньше: каждой программе по имени процесса назначается свой прокси, а всё остальное идёт напрямую. Так браузер для работы может выходить через один адрес, парсер через другой, а мессенджер и обновления Windows через обычное подключение.

  • Прокси для всей системы: один адрес на весь компьютер, удобно, когда так требует корпоративная сеть.
  • Прокси для отдельных программ: правила по процессам вроде chrome.exe или python.exe, применяются кнопкой APPLY SPLIT TUNNELING.

Протоколы, авторизация и проверка

Поддерживаются HTTP (через метод CONNECT) и SOCKS5, оба с логином и паролем. Адрес можно вставить в одном из трёх форматов: http://user:pass@ip:port, socks5://user:pass@ip:port или ip:port:user:pass. Перед подключением HTTP-прокси проверяется кнопкой VERIFY: программа покажет, отвечает ли сервер, его страну, город и внешний IP. Последние прокси сохраняются в истории, а длинный список можно загрузить из файла во вкладке Proxy List. Внизу окна всегда видны скорость отдачи и загрузки, время подключения и пинг.

Ограничения, о которых лучше знать заранее

Через прокси идёт только TCP. UDP, на котором держатся голосовые звонки и большинство онлайн-игр, уходит напрямую, поэтому для игр и звонков программа не подходит. DNS-запросы по умолчанию тоже идут напрямую, это регулируется настройкой DNS Bypass. С включённым VPN-клиентом (WireGuard, AmneziaWG, OpenVPN) ProxyBridge работает плохо, на время работы VPN нужно выключить. И главное: сами прокси программа не продаёт, их покупают у провайдера.

Кому подойдёт

Программа для прокси на ПК полезна тем, кто работает с несколькими аккаунтами, собирает данные, снимает позиции, тестирует сайты из разных регионов или просто обязан ходить в сеть через прокси компании. Если у тебя Mac, есть бета-версия с одним системным режимом.

Программа платная: ключ стоит от 99 ₽ за месяц, бессрочный ключ 699 ₽. Один ключ работает на двух устройствах, например на рабочем и домашнем ПК, лишнее устройство отвязывается в Settings. Проверка ключа кэшируется, так что без интернета программа продолжит работать до 7 дней. Исходный код открыт на GitHub под лицензией MIT.

Частые вопросы

Какой прокси клиент для Windows 11 выбрать, если программа не видит системный прокси?

Нужен клиент, который перехватывает трафик на уровне драйвера, а не полагается на настройки приложения. ProxyBridge так и работает: программе не нужны свои поля для прокси.

Можно ли в Windows задать прокси с логином и паролем без сторонних программ?

В параметрах Windows есть только адрес и порт, логин браузер спросит сам при первом запросе. Другие программы такое окно обычно не показывают, поэтому авторизованный прокси проще задать через клиент.

ProxyBridge работает на Windows 7 или 32-битной системе?

Нет, поддерживаются только Windows 10 и 11 в 64-битной версии.
