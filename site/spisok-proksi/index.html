Список прокси: импорт из файла и переключение в один клик

Когда прокси десятки, копировать их по одному надоедает быстро. Вкладка Proxy List в ProxyBridge загружает весь список из файла, а подключиться к любому адресу можно одной кнопкой.

Зачем менеджер прокси, если есть буфер обмена

Менеджер прокси нужен тем, у кого адресов больше двух-трёх. Провайдеры обычно отдают купленный пакет одним текстовым файлом: строка на прокси, иногда сотня строк. Держать такой файл в блокноте и копировать нужную строку в поле подключения можно, но это медленно и легко ошибиться, вставив не ту строку или обрезав пароль. А переключение прокси в Windows встроенными средствами означает каждый раз открывать «Параметры» и перепечатывать адрес и порт, причём пароль там не задать вовсе.

В Proxy List файл загружается целиком кнопкой Load from File. Каждый прокси появляется отдельной строкой со своей кнопкой Connect. Нажал, и программа переключилась на этот адрес. Кнопка Clear List очищает список, когда пакет закончился или пора загрузить новый.

Как сделать в ProxyBridge

  1. Сохрани прокси от провайдера в текстовый файл, по одному адресу в строке.
  2. Открой вкладку Proxy List и нажми Load from File.
  3. Выбери файл и дождись, пока список появится в окне.
  4. Нажми Connect напротив нужного прокси.
  5. Чтобы сменить адрес, нажми Connect у другой строки, а для нового пакета очисти список кнопкой Clear List.

Список и история: в чём разница

У ProxyBridge есть два места, где хранятся прокси. История на вкладке Dashboard заполняется сама: туда попадают последние использованные адреса, и клик подставляет прокси в поле. Proxy List заполняешь ты, загрузкой из файла. История подходит для двух-трёх постоянных прокси, список для пакета, который ты купил под задачу и будешь перебирать.

  • Файл готовь в тех же форматах, что принимает поле подключения: http://user:pass@ip:port, socks5://user:pass@ip:port или ip:port:user:pass.
  • Удобно держать отдельный файл на каждый проект или страну и загружать нужный.
  • Если в файле перепутан порядок полей, исправь его до загрузки, а не после.
  • После очистки кнопкой Clear List файл на диске остаётся, его можно загрузить снова.

Как подготовить файл со списком

Удобнее всего выгрузить прокси из кабинета провайдера в формате, который программа уже понимает, без лишних колонок и комментариев. Если провайдер отдаёт таблицу с адресом, портом, логином и паролем в разных столбцах, собери из них строки вида ip:port:user:pass в любом табличном редакторе и сохрани как обычный текст. Проверь, что в конце строк нет пробелов, а протокол понятен: для SOCKS5 надёжнее явно указать префикс socks5://. Если в пакете перемешаны HTTP и SOCKS5, лучше разделить их на два файла.

Типичный рабочий цикл

Пример: SEO-специалист снимает позиции, и компьютер работает через прокси в системном режиме. Утром он загружает файл с пакетом, подключается к первому адресу и запускает съём. Если пинг внизу окна пропал или скорость упала до нуля, он нажимает Connect у следующей строки и продолжает. Последние использованные адреса сами окажутся в истории, и к удачному прокси легко вернуться на следующий день. Если HTTP-адрес вызывает сомнения, его можно перед подключением вставить в поле на Dashboard и проверить кнопкой VERIFY. Правила по программам задаются отдельно, на вкладке Split Tunnel.

Какие задачи решает

  • Импорт списка прокси из файла провайдера без ручного копирования.
  • Быстрое переключение прокси в Windows, когда текущий адрес перестал отвечать.
  • Ручная смена IP между сессиями парсинга или проверки позиций.
  • Перебор адресов разных стран при тестировании сайта.
  • Хранение рабочего пакета прокси в одном окне рядом с кнопкой подключения.

Чего Proxy List не делает

Переключение здесь ручное. Автоматической ротации по таймеру или по числу запросов в программе нет, и если твоей задаче нужна смена IP на каждый запрос, это обычно решается ротационными прокси на стороне провайдера: у них один адрес подключения, а внешний IP меняется на сервере. Массовой проверки всего списка тоже нет, VERIFY проверяет по одному HTTP-прокси за раз. Сами прокси программа не выдаёт, список берётся у провайдера, ссылки на некоторых есть на странице провайдеров. Список не синхронизируется с кабинетом провайдера: если пакет продлили с новыми адресами, файл нужно загрузить заново.

Уточнение: Proxy List хранит загруженный тобой файл целиком, а история прокси сама запоминает только последние адреса, к которым ты подключался.

Частые вопросы

Как импортировать список прокси из файла в программу?

В ProxyBridge открой вкладку Proxy List и нажми Load from File. Подойдёт обычный текстовый файл с прокси в форматах ip:port:user:pass или socks5://user:pass@ip:port.

Есть ли в ProxyBridge автоматическая ротация прокси?

Нет, переключение ручное: кнопка Connect у нужной строки. Для смены IP на каждый запрос используй ротационные прокси провайдера.

Как быстро переключать прокси в Windows без перенастройки программ?

Программам не нужны свои настройки, если трафик перехватывает клиент. В ProxyBridge смена прокси занимает один клик в Proxy List или в истории.
