Прокси-клиент для macOS (бета)

Что умеет прокси-клиент для Mac

Прокси-клиент для Mac в ProxyBridge работает в одном режиме: системном. После подключения весь TCP-трафик компьютера идёт через выбранный прокси, протокол на выбор HTTP или SOCKS5, с логином и паролем. Формат адреса тот же, что на Windows: socks5://user:pass@ip:port или http://user:pass@ip:port. В главном окне это значит, что используется только строка «Все остальные программы»: в ней выбирается прокси для всего Mac. Бета запускается на macOS 12 и новее, на процессорах Apple Silicon и Intel.

Чем это отличается от встроенных настроек? В «Системных настройках» macOS в разделе сети можно вписать веб-прокси и SOCKS-прокси для текущего подключения. Этого хватает браузерам и программам, которые читают системные параметры. Приложения со своим сетевым кодом, часть консольных утилит и некоторые клиенты эти поля пропускают. ProxyBridge забирает их трафик принудительно, поэтому SOCKS5 клиент на macOS не зависит от того, поддерживает ли программа прокси.

Как сделать в ProxyBridge

  1. Скачай версию для macOS на главной странице в разделе «На связи».
  2. Перенеси приложение в «Программы» и открой его правым щелчком через пункт «Открыть».
  3. Введи ключ лицензии при первом запуске.
  4. На вкладке «Прокси» вставь адрес в формате socks5://user:pass@ip:port или http://user:pass@ip:port и нажми «Добавить».
  5. На вкладке «Главная» выбери этот прокси в строке «Все остальные программы».
  6. Нажми «Подключить» и введи пароль администратора macOS.

Ограничения бета-версии

Честно о том, чего на Mac пока нет. Если тебе важен какой-то из пунктов ниже, рассмотри версию для Windows или подожди обновлений.

  • Нет режима по программам (split tunneling): назначить разным программам разные прокси нельзя, работает только строка «Все остальные программы», то есть весь компьютер целиком.
  • Только TCP: UDP (звонки, многие игры, часть видео) идёт мимо прокси.
  • DNS-запросы идут напрямую.
  • Приложение не подписано Apple, поэтому Gatekeeper при первом запуске его остановит.
  • При подключении macOS запросит пароль администратора.

Перед первым подключением

Прокси для Mac покупается так же, как для Windows: у провайдера или на сайте ProxyBridge, на странице «Купить прокси». Сначала добавь адрес на вкладке «Прокси» и выбери его в строке «Все остальные программы» на вкладке «Главная». После «Подключить» открой в браузере любой сайт проверки IP: там должен быть адрес прокси. Помни, что DNS в бете идёт напрямую, поэтому сервисы проверки DNS покажут резолвер твоего интернет-провайдера, а не прокси. Звонки в мессенджерах и онлайн-игры на Mac, как и на Windows, работают в основном по UDP и через прокси не пойдут. Если что-то не работает, напиши в поддержку в Telegram @inter1ark или на support@proxybridge.org: отчёты о проблемах в бете особенно полезны.

Первый запуск неподписанного приложения

Двойной щелчок по неподписанной программе macOS заблокирует с предупреждением. Это нормально для приложений без сертификата Apple. Открой «Программы», щёлкни по ProxyBridge правой кнопкой, выбери «Открыть» и подтверди. Дальше приложение запускается как обычно. Пароль администратора при подключении нужен, чтобы программа могла перенаправлять сетевые соединения системы. Исходный код открыт на GitHub, его можно посмотреть до установки.

Кому подойдёт программа для прокси на MacBook

Бета удобна, если весь MacBook должен выходить в сеть через один адрес: корпоративный прокси, тестирование сайта из нужного региона, работа с сервисом, который пускает только с определённого IP. Например, разработчик смотрит, как его сайт видят посетители из другой страны, или аналитик выгружает данные из сервиса, доступного только с адреса компании. Если же нужно развести программы по разным прокси, сейчас это умеет только версия для Windows. Один ключ работает на двух устройствах, лишнее устройство отвязывается на вкладке «Настройки» кнопкой «Отвязать устройство».

Частые вопросы

Как настроить прокси на макбуке для всех программ?

Встроенные настройки сети macOS работают только в программах, которые их читают. Чтобы весь TCP-трафик шёл через прокси принудительно, нужен клиент вроде бета-версии ProxyBridge.

Почему macOS пишет, что приложение ProxyBridge нельзя открыть?

Приложение не подписано Apple, и Gatekeeper блокирует его при двойном щелчке. Открой его правой кнопкой мыши через пункт «Открыть», это нужно сделать один раз.

Есть ли в версии для Mac прокси для отдельных приложений?

Пока нет: бета поддерживает только системный режим. Разные прокси для разных программ доступны в версии для Windows.
