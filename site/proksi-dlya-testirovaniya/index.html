Что проверяют через прокси

Прокси для тестирования нужны, когда поведение продукта зависит от IP пользователя. Чтобы проверить сайт из другой страны, мало сменить язык в браузере: сервер определяет регион по адресу и на этом строит ответ. Типичный набор проверок:

  • локализация: язык по умолчанию, формат дат, валюта, перевод интерфейса;
  • геозависимые цены, налоги и способы оплаты в корзине;
  • баннеры о cookie и юридические тексты для отдельных регионов;
  • редиректы на региональные домены;
  • ограничения доставки и каталога по странам;
  • десктопное приложение, которое при запуске запрашивает конфигурацию для своего региона.

Как сделать в ProxyBridge

  1. Установи ProxyBridge от имени администратора и введи ключ.
  2. На вкладке «Прокси» загрузи адреса нужных стран через «Импорт из файла» и переименуй их по странам.
  3. Нажми «Проверить все» и сверь страну и город каждого адреса.
  4. На вкладке «Главная» нажми «Добавить программу» и выбери тестовый браузер или приложение, например firefox.exe.
  5. Справа в строке выбери прокси нужной страны, нажми «Подключить» и запускай прогон.

Рабочая схема для QA

Отдельный браузер только для тестов, например Firefox, получает свой прокси в строке на вкладке «Главная», а основной Chrome с документацией и трекером работает напрямую через «Все остальные программы». Для смены страны загрузи адреса на вкладку «Прокси» через «Импорт из файла» и выбирай нужный в строке браузера: изменение применяется сразу, даже во время подключения. Кнопка «Проверить» для HTTP и SOCKS5 показывает страну, город, внешний IP и задержку, так что перед прогоном видно, из какого региона ты заходишь.

Есть нюансы. Браузеры открывают часть сайтов по HTTP/3 (QUIC), а он работает поверх UDP и идёт мимо прокси: для геотестов отключи QUIC в тестовом браузере. DNS-запросы всегда идут напрямую, поэтому CDN, выбирающий узел по DNS, может отдать ближайший к тебе сервер. Часовой пояс и язык браузера прокси не меняет, их выставляют отдельно. Базы геолокации у сервисов разные, и город на сайте может отличаться от показанного после «Проверить».

Перед прогоном

Если тесты автоматизированы через Selenium или Playwright, у фреймворков есть свои параметры прокси при запуске браузера, и для параллельных прогонов из разных стран удобнее они. ProxyBridge пригодится, когда тестируемая программа не даёт задать прокси или нужно проверить её как есть, без доработок.

  • Проверь адрес кнопкой «Проверить» на вкладке «Прокси» и для верности открой страницу определения IP в тестовом браузере.
  • Очисти cookie и кэш тестового браузера: сайт мог запомнить регион с прошлого визита.
  • Запиши в баг-репорт страну, город и IP прокси, чтобы разработчик мог воспроизвести проблему.
  • Посмотри задержку внизу главной ProxyBridge: медленный прокси искажает замеры скорости загрузки.

Какие прокси подходят для QA

Для большинства проверок хватает серверных IPv4 в нужных странах: они недорогие, и их легко держать набором под каждый целевой рынок. Если продукт по-разному ведёт себя для мобильных сетей или домашних провайдеров, понадобятся мобильные или резидентные адреса. IPv6-прокси пригодятся, чтобы проверить работу сайта по IPv6. Прокси для QA покупают у провайдеров, их список есть на странице провайдеров.

Ограничения ProxyBridge: один прокси на процесс, только TCP, автоматической смены адреса нет. Если для доступа к стенду ты подключаешься через корпоративный VPN-клиент (WireGuard, AmneziaWG или подобный), выключать его не нужно: ProxyBridge работает вместе с ним.

Частые вопросы

Как проверить сайт из другой страны?

Назначь отдельному браузеру прокси этой страны и открой сайт. В ProxyBridge это строка браузера на вкладке «Главная», а страну прокси можно заранее проверить кнопкой «Проверить».

Почему сайт через прокси всё равно видит мой регион?

Частые причины: браузер пустил часть трафика по QUIC (UDP идёт мимо прокси), сайт смотрит на язык и часовой пояс системы или база геолокации относит IP к другому городу. Отключи QUIC и выставь язык и часовой пояс под нужный регион.

Можно ли тестировать десктопное приложение через прокси?

Да, если оно работает по TCP. Добавь его кнопкой «Добавить программу» на вкладке «Главная» и назначь прокси, настройки прокси в самом приложении не нужны.
