Country flags (48x36 PNG, 4:3), one file per ISO 3166-1 alpha-2 code in lower case (de.png, nl.png).

Source: https://flagcdn.com (https://flagcdn.com/48x36/<code>.png, code list https://flagcdn.com/en/codes.json).
The flag images from flagcdn are in the public domain.

Used by Controls/FlagImage.cs; an unknown code falls back to a neutral globe icon.
